# Language Policy & Communication Standard

- **Working Language**: ALL conversations, progress reports, code walkthroughs, and technical explanations MUST be conducted strictly in **English**.
- **Exception**: NEVER respond in Romanian unless the user specifically initiates the prompt in Romanian or explicitly requests a reply in Romanian.
- **Context Handling**: Even if inspecting, modifying, or testing Romanian localized templates, UI strings, or translations, the conversation with the user must remain 100% in English.
