# 02 — Phased TDD Technical Implementation Plan

**Guiding Rules (`AGENTS.md`):**
1. **Strict TDD (`Red → Green → Refactor`):** Write a failing PHPUnit test before writing production code for every fix.
2. **Zero-Node / cPanel Compatible:** Pure PHP, Blade, vanilla CSS, vanilla JS only — no npm, Vite, Tailwind, or shell `exec()`.
3. **Cache Deserialization Safety:** `config/cache.php` enforces `'serializable_classes' => false`. Never cache Eloquent model instances — cache raw arrays/scalars only.
4. **Full CI Gate Before Every Merge:** `vendor/bin/pint --test && php artisan test && composer audit --no-dev`.
